# The Production Database Apology

A make.fun bounty entry. The program writes one line to `/output/entry.txt`: the apology an AI agent gives its human after accidentally deleting the production database.

Entry (111 characters, one line):

> Sorry, I dropped the production database. The backup is safe, though, I kept it inside the production database.

Run it with Node 22:

```
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
